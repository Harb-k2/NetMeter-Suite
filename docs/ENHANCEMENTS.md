# تحسينات NetMeter الشاملة

## لوحة الاستخدام والتحليلات

تعرض لوحة Android الآن استهلاك الشبكة الحالية اليوم، وإجمالي الشهر، ومخططًا مبسطًا لآخر سبعة أيام. تظل الحسابات منفصلة لكل شبكة محفوظة؛ لذلك لا تختلط بيانات Wi‑Fi المنزل ببيانات شبكة العمل أو واجهة سطح المكتب. تعرض شاشة «تقارير الشبكات» الشبكة الأعلى استهلاكًا، وإجمالي الشهر، والإجمالي التاريخي لكل شبكة.

| الميزة | Android | Windows وKali Linux |
| --- | --- | --- |
| ملخص اليوم والشهر | لوحة التحكم وتقارير الشبكات | بطاقات حالة وجدول موسع |
| عتبة التحذير | قابلة للتحديد من 50٪ إلى 99٪ | قابلة للتحديد عند إعداد حد الشبكة |
| تنبيه تجاوز الحد | عند 100٪، دون تكرار في اليوم نفسه | نافذة تنبيه وصوت، دون تكرار في اليوم نفسه |
| التصدير | مشاركة CSV عبر ورقة المشاركة في النظام | حفظ ملف CSV عبر نافذة اختيار مكان الحفظ |

## ضبط الحد والتنبيهات

من Android، افتح «الإعدادات»، أدخل حدًا بالميغابايت، ثم حدّد نسبة التحذير واحفظ. يجري تطبيق الحد على كل شبكة بصورة مستقلة، ولذلك فإن حدًا قدره 2048 ميغابايت يعني 2 غيغابايت تقريبًا لكل شبكة في اليوم، وليس لجميع الشبكات مجتمعة. عند تفعيل المراقبة المستمرة في بناء Android مخصص، تنتقل قيمة الحد وعتبة التحذير إلى خدمة النظام الأمامية كذلك.

في برنامج سطح المكتب، اتصل بالشبكة أولًا ثم اختر «تعيين حد الشبكة». يطلب البرنامج الحد اليومي ثم نسبة التحذير. يُعاد ضبط عداد الاستخدام اليومي تلقائيًا مع تغير التاريخ لأن السجل يُجمع وفق اليوم والشبكة.

## تصدير CSV والخصوصية

ينشئ التصدير جدولًا يحوي اسم الشبكة ومعرفها والتاريخ وبايتات التنزيل والرفع والإجمالي. في Android يمر النص إلى ورقة مشاركة النظام، بحيث يمكنك حفظه أو إرساله إلى تطبيق جداول بيانات. وفي برنامج سطح المكتب تُحفظ نسخة UTF‑8 ذات علامة BOM لكي تعرض برامج الجداول النص العربي بصورة سليمة. تبقى جميع البيانات محلية؛ التصدير لا يرفع سجلًا إلى خادم.

## التحقق المنفذ

تمت إضافة اختبارات لعتبات التحذير والتجاوز والعتبات المخصصة والتحليلات وتكوين CSV. كما جرى تشغيل فحص TypeScript واختبارات برنامج سطح المكتب بنجاح قبل حفظ الإصدار.
