# دليل تثبيت وتشغيل NetMeter

## قبل البدء

يعمل **NetMeter** محليًا؛ لذلك تبقى أسماء الشبكات وقياسات السرعة وسجل الاستهلاك على الجهاز. يبدأ العداد بتسجيل فروق البيانات بعد تشغيل التطبيق أو برنامج سطح المكتب، ولا يعيد بناء الاستهلاك الذي حدث قبل التثبيت أو قبل بدء المراقبة. يختلف أسلوب التثبيت حسب المنصة كما يبين الجدول التالي.

| المنصة | الأسهل للمستخدم | ما تحتاجه |
| --- | --- | --- |
| Android | إنشاء ملف APK من زر **Publish** في واجهة المشروع ثم تثبيته | هاتف Android وجهاز يدعم تثبيت التطبيق |
| Windows | بناء نسخة محمولة من مجلد `desktop` ثم تشغيل الملف التنفيذي | Windows 10/11 وPython 3 |
| Kali Linux | تشغيل البرنامج من المصدر أو بناء ملف محلي | Kali Linux وPython 3 وواجهة Tkinter |

> لا تستخدم نسخة Expo Go لمراقبة Wi‑Fi وعدادات الاستهلاك أو للودجت والنسخ المشفر، لأن هذه الوظائف تحتاج بناء Android مخصصًا يحتوي على الوحدة الأصلية.

## تثبيت Android

### الطريقة الموصى بها: إنشاء APK من واجهة المشروع

افتح أحدث إصدار للمشروع في واجهة NetMeter ثم اختر زر **Publish** من أعلى الواجهة. سيبدأ النظام إنشاء حزمة Android؛ بعد اكتمال البناء نزّل ملف APK إلى هاتفك أو انقله إليه عبر USB أو أي وسيلة نقل موثوقة. لا تحاول بناء ملف APK يدويًا داخل بيئة التطوير؛ استخدم زر النشر لأنه يهيئ عملية البناء للحزمة المطلوبة.

على الهاتف، افتح ملف APK. إن ظهر تحذير من Android حول التثبيت من مصدر غير معروف، افتح **الإعدادات** من شاشة التحذير، ثم امنح تطبيق مدير الملفات أو المتصفح الذي فتحت منه الملف صلاحية *السماح بالتثبيت من هذا المصدر*. ارجع إلى الملف واضغط **تثبيت**. بعد انتهاء التثبيت، افتح NetMeter من قائمة التطبيقات.

| الخطوة | ما يجب تنفيذه داخل التطبيق | السبب |
| --- | --- | --- |
| 1 | افتح **الإعدادات** واضبط الحد اليومي وعتبة التحذير | يطبق الحد بصورة مستقلة على كل شبكة |
| 2 | فعّل **تنبيهات حد البيانات** وامنح إذن الإشعارات عند الطلب | لعرض التحذير عند الاقتراب من الحد أو تجاوزه |
| 3 | افتح **إحصاءات الاستخدام** من الزر المخصص وامنح NetMeter الإذن | لتحسين قراءة عدادات البيانات حسب سياسة الجهاز |
| 4 | اسمح بالموقع وWi‑Fi عند طلب Android | يتيح إظهار اسم شبكة Wi‑Fi عندما يسمح الجهاز بذلك |
| 5 | فعّل **المراقبة المستمرة** إن كنت تحتاج تحديثات أثناء عدم فتح الواجهة | يشغّل خدمة أمامية مع إشعار نظامي منخفض الأهمية |

تطلب أجهزة Android الحديثة إذنًا وقت التشغيل لبعض معلومات Wi‑Fi، كما تقيّد العمل الخلفي بحسب سياسة البطارية. لهذا يوصى بإيقاف تقييد البطارية لتطبيق NetMeter عند الحاجة إلى مراقبة طويلة؛ ابحث في إعدادات الهاتف عن **البطارية** ثم **تحسين البطارية** أو **استخدام البطارية**، واختر NetMeter واجعله غير مقيّد إن كان ذلك مناسبًا لك [1] [2].

### إضافة ويدجت Android

بعد تثبيت بناء Android المخصص، اضغط مطولًا على مساحة فارغة من الشاشة الرئيسية، واختر **Widgets** ثم ابحث عن **NetMeter** واسحب الودجت إلى الشاشة. يعرض الودجت اسم الشبكة واستهلاك اليوم ونسبة الحد. اضغط زر التحديث داخله لطلب قراءة جديدة، أو فعّل المراقبة المستمرة في التطبيق لتحديثه مع خدمة المراقبة.

### الوضع الليلي والنسخة الاحتياطية

من **الإعدادات**، اختر وضع **تلقائي** لاتباع سمة الهاتف، أو الوضع الفاتح أو الليلي يدويًا. يمكن تفعيل «تقليل الحركة» لخفض الانتقالات. لإنشاء نسخة احتياطية، أدخل كلمة مرور من ثمانية أحرف على الأقل في قسم النسخ الاحتياطي، ثم احفظ النص المشفر في مكان موثوق. لاستعادة البيانات، أدخل النص نفسه وكلمة المرور نفسها؛ لا يحتفظ التطبيق بكلمة المرور ولا يمكن استرداد نسخة مشفرة عند فقدانها.

## تشغيل Windows

### تشغيل سريع من المصدر

ثبّت Python 3 من [الموقع الرسمي](https://www.python.org/downloads/windows/) وحدد خيار **Add Python to PATH** أثناء التثبيت. نزّل ملفات المشروع وافتح PowerShell داخل مجلد المشروع، ثم نفّذ الأوامر التالية:

```powershell
cd desktop
py -m pip install -r requirements.txt
py netmeter_desktop.py
```

يعرض البرنامج النافذة المحلية ويخزن قاعدة البيانات في المسار `C:\Users\<اسمك>\.netmeter-suite\netmeter.sqlite3`. اترك النافذة مفتوحة لتستمر المراقبة؛ يحسب البرنامج الفروقات كل خمس ثوانٍ ويعرض اسم Wi‑Fi عندما يستطيع Windows توفيره.

### إنشاء نسخة محمولة قابلة للتشغيل

افتح PowerShell في مجلد `desktop` وشغّل:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\build_windows.ps1
```

بعد النجاح، افتح مجلد `desktop\dist\NetMeterSuite` وشغّل `NetMeterSuite.exe`. انسخ المجلد كاملًا عند نقله إلى جهاز آخر؛ لا تنقل ملف EXE وحده إن كانت أدوات البناء قد وضعت معه ملفات تشغيل مساندة. يمكن إنشاء اختصار للملف التنفيذي على سطح المكتب أو إضافته إلى بدء التشغيل إذا أردت بدء المراقبة يدويًا بعد تسجيل الدخول.

## تشغيل Kali Linux

افتح الطرفية، ثم ثبّت المتطلبات النظامية اللازمة للواجهة الرسومية مرة واحدة:

```bash
sudo apt update
sudo apt install -y python3 python3-pip python3-tk
```

انتقل إلى مجلد المشروع وشغّل البرنامج من المصدر:

```bash
cd desktop
python3 -m pip install --user -r requirements.txt
python3 netmeter_desktop.py
```

لإنشاء نسخة محلية قابلة للتشغيل على Kali، نفّذ:

```bash
cd desktop
chmod +x build_linux.sh
./build_linux.sh
./dist/NetMeterSuite/NetMeterSuite
```

يخزن البرنامج البيانات في `~/.netmeter-suite/netmeter.sqlite3`. في Kali، يحاول البرنامج الحصول على اسم الشبكة باستخدام `nmcli` أو `iwgetid`. إذا لم تتوفر الأدوات أو الصلاحيات، يحفظ السجل باسم واجهة الشبكة بدلًا من دمج بيانات الشبكات المختلفة.

## الاستخدام اليومي

ابدأ من لوحة التحكم، اضغط **تحديث القراءة** لتسجيل لقطة جديدة، ثم اضغط **بدء قياس السرعة** عند الحاجة فقط؛ اختبار السرعة يستهلك بيانات حقيقية. افتح تبويب **التقويم** لمراجعة استهلاك الشهر الحالي ومقارنته بالشهر السابق، وافتح **الشبكات** لمراجعة كل شبكة على حدة. يمكن تصدير السجل بصيغة CSV من Android من خلال ورقة المشاركة، أو من برنامج سطح المكتب إلى ملف CSV.

## استكشاف الأخطاء الشائعة

| المشكلة | السبب المحتمل | الحل |
| --- | --- | --- |
| يظهر «اسم غير متاح» في Wi‑Fi | لم يمنح Android إذن الموقع/Wi‑Fi أو حجبه النظام | امنح الإذن من إعدادات التطبيق، ثم أعد فتح التطبيق |
| الاستهلاك صفر رغم وجود اتصال | لا توجد لقطة سابقة للمقارنة أو لم تمنح إحصاءات الاستخدام | اضغط تحديث مرتين بفاصل قصير، وفعّل إحصاءات الاستخدام |
| لا يظهر تنبيه | إذن الإشعارات مغلق أو لم تصل نسبة الحد | فعّل التنبيهات من التطبيق ومن إعدادات Android، وتحقق من الحد والعتبة |
| لا يظهر الودجت | تم تشغيل نسخة معاينة أو لم يُثبت APK مخصص | ثبّت APK الناتج من Publish، ثم أعد البحث في Widgets |
| لا يمكن استعادة النسخة | كلمة المرور أو النص المشفر غير صحيح | استخدم النص الأصلي وكلمة المرور المطابقة؛ لا توجد طريقة لاستعادة كلمة مرور مفقودة |
| لا تعمل واجهة Kali | حزمة Tkinter غير مثبتة | نفّذ `sudo apt install python3-tk` ثم أعد التشغيل |
